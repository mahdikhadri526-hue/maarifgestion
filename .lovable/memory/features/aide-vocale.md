---
name: Aide vocale par rubrique
description: Explications audio enregistrées dans l’application par l’administrateur principal, écoutables par tous dans chaque rubrique.
type: feature
---
Chaque rubrique interne de chaque table doit proposer une explication audio courte avec la propre voix de l’administrateur principal. L’enregistrement et le remplacement se font directement dans l’application. Tous les utilisateurs autorisés à voir la rubrique peuvent écouter; seul l’administrateur principal peut gérer les audios.
